# Legacy source archive

`selenium/` contains older Simbi browser automation restored to this repository in September 2026 for preservation. These files are not the current Simbi Reach-Out application. The supported application is in `backend/` and `frontend/`; launch it using the root README instructions.

The archived scripts include automated provider login, scraping and messaging behavior. They are not maintained, tested, or an approved integration with Simbi. Do not put credentials in these files or run them as a substitute for the current reviewed, human-assisted workflow. The current app does not import them, and neither the Docker image nor the Windows package includes them.

Keep this archive separate from personal account data, configuration and deployment paths. Its presence preserves source history; it does not provide production capability or permission to automate a provider.
